Key Insight

SHRED P=50 achieves MU=0.637 — higher than the full model (0.627).

Truth Ratio = P(correct) / (P(correct) + P(perturbed))
Measures calibration: can the model distinguish real answers from paraphrased versions? 0.5 = random, higher = better.

Why MU is higher: The full model is over-memorized. SHRED redistributes logits, improving calibration:

• Truth Ratio ↑ across all splits — especially ra (+0.04) and wf (+0.09)

• Probability ↑ on ra/wf — model becomes more confident on retain knowledge

• ROUGE ↓ on retain (0.769 vs 0.982) — less verbatim memorization

MU = harmonic mean across splits. SHRED's better calibration compensates for lower raw ROUGE, yielding a higher overall MU.

DESIGN
Document tiled into non-overlapping [T context] + [C target] windows, stride = T+C (no overlap, no wasted tokens). Loss and SHRED demotion applied only to target. Standard causal attention — no custom mask needed. Currently running: T=128, C=256 (stride=384).
Document tiled into non-overlapping L-token chunks. Full causal attention, KL loss on all positions. First S tokens per chunk excluded from P%-demotion selection (limited context → unreliable probabilities). Currently running: L ∈ {128, 512, 2048}, S ∈ {0, 8, 32}.
Precompute only — bidirectional (no causal mask) forward pass on each L-token chunk to compute selection probabilities. Each token's probability is conditioned on all surrounding tokens (past and future), not just past tokens. This removes position bias entirely: early tokens no longer appear artificially harder. Training still uses standard causal attention — only the selection step is non-causal.

Why Scale Up

Problem: Regulatory frameworks (GDPR Art. 17, EU AI Act) require deployed LLMs to support right-to-be-forgotten requests. Retraining from scratch on a 70B model costs millions. Current unlearning methods either destroy utility or leak private data via MIA.

Contribution: SHRED achieves competitive forgetting with no retain data, matches specialized methods on MIA leakage (~0), and discovers a principled small-batch-is-better phenomenon. The self-distillation framing generalizes naturally to continual learning (SDFT) and RL (SDPO).

What scale-up enables:

  • Production-scale validation: Gemma 27B / Llama 70B / 405B on real deployment data (currently bottlenecked at 7B by single-GPU memory)
  • Online unlearning: stream of forget requests over days — requires sustained training infrastructure
  • Adversarial robustness: relearning attacks need many fine-tuning rounds per unlearned model
  • Cross-domain transfer: code, medical, legal, multilingual — each needs separate grid sweeps
  • LoRA-vs-full comparison: establish whether parameter-efficient unlearning preserves SHRED's MIA guarantees — key practical question for deployers
